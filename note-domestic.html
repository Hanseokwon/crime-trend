경남 가정폭력 112 통계와 마산중부 적용

경찰112경남마산중부경찰서가정폭력통계분석 · 작성 2026-10-28

개요

경찰청 공개 시도청별 통계에서 확인되는 경남 전체 가정폭력 112 신고 접수 건수를 살펴보고, 마산중부경찰서 업무에 적용할 분석 질문을 정리합니다. 도 단위 수치는 마산중부서 실적이나 관할의 발생량이 아닙니다.

시각 자료: 경남 통계·마산중부 적용 (웹페이지)

핵심 내용

확인된 경남 통계

2021년 대비 2025년 접수 건수는 5,700건(+52.5%) 늘었고, 2025년은 전년보다 3,174건(+23.7%) 많습니다. 이는 신고 접수량의 변화이며 실제 발생 증가 원인, 고유 사건 수, 피해자 수, 위험도 또는 대응 성과를 뜻하지 않습니다.

공개 파일은 시도청별·연도별 가정폭력 신고 건수입니다. 공개 자료에서 마산중부경찰서 단위 수치나 경남의 교제폭력·스토킹 연도별 수치는 확인하지 못했습니다. 따라서 다른 유형의 전국 통계를 경남 통계와 합산하지 않습니다.

치안 트렌드 4단계 적용

  1. 트리거: 2025년 경남 가정폭력 코드 접수가 16,550건으로 2024년보다 23.7% 증가했습니다.
  2. 메커니즘: 공개 연간표만으로 증가 원인은 알 수 없습니다. 반복 접수 여부, 월별 분포, 신고 유형·처리 결과의 변화가 있었는지는 권한 있는 내부 집계로 별도 확인할 질문입니다.
  3. 체인지: 2021~2025년 연간 추이는 상승했으며, 특히 2025년 증가 폭이 컸습니다. 계절성이나 지역별 편차를 이 연간 도 통계로 추정할 수 없습니다.
  4. 임팩트: 마산중부서의 승인된 비식별 집계와 기간·분류 기준을 맞춰 비교하면, 도 추세가 관서 자료에서도 관찰되는지 확인할 수 있습니다. 비교 전에는 신고 코드, 기간, 중복 처리, 분모를 맞춰야 합니다.

인사이트

  • 경남 통계는 마산중부서 분석의 비교 배경선으로 활용할 수 있지만, 관서 실적을 대체하지 않습니다.
  • 다음으로 유용한 검토는 관서별 월·분기 집계의 기준을 맞춘 뒤 경남 연간 추세와 방향이 같은지 보는 것입니다. 자료가 없으면 결과는 미확인으로 둡니다.
  • 공개 집계로는 원인·개별 위험·출동 판단을 도출하지 않습니다. 실시간 112 접수·위험성 평가·지령은 공식 시스템과 내부 절차를 따릅니다.

실행할 일

  • 내부 승인·비식별 절차에 따라 마산중부서의 동일 정의 연도별 또는 월별 집계 확보 가능 여부 확인
  • 비교 시 기간, 신고 코드, 중복 처리 기준을 경남 공개 통계와 대조
  • 교제폭력·스토킹의 경남 단위 공개 통계가 추가 제공되는지 경찰청·경남청 공개자료 갱신 시 확인
